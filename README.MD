# SauceDemo Playwright TypeScript Automation

This project was created with AI assistance as an educational demonstration of end-to-end browser automation testing for the SauceDemo demo application using Playwright and TypeScript.

## Overview

The test suite covers core user journeys such as:

- Login flows
- Account profile validation
- Product inventory and cart interactions
- Checkout flow
- Dynamic catalog slider behavior

The project follows a Page Object Model (POM) structure to keep the tests readable, reusable, and maintainable.

## Tech Stack

- TypeScript
- Playwright
- Node.js
- SauceDemo demo website

## Prerequisites

Before running the tests, make sure you have:

- Node.js installed
- npm installed
- Playwright browser dependencies installed

## Installation

```bash
npm install
npx playwright install
```

## Running Tests

Run the full suite:

```bash
npm test
```

Run tests in headed mode:

```bash
npm run test:headed
```

Open the Playwright UI mode:

```bash
npm run test:ui
```

## Configuration

The Playwright configuration is defined in `playwright.config.ts` and uses:

- `testDir: ./tests`
- base URL: `https://www.saucedemo.com`
- HTML reporter
- Chromium, Firefox, and WebKit projects

## Environment Variables

The config loads a `.env` file if present from the project root. This is useful for any environment-specific setup you may add later.

Example:

```env
BASE_URL=https://www.saucedemo.com
```

## Notes

- Tests are designed to validate real browser behavior against the SauceDemo app.
- The suite uses page objects under `tests/pages` to centralize selectors and interactions.
- HTML test reports are generated by Playwright and stored in the `playwright-report` folder.

## Useful Commands

```bash
npx playwright test --project=chromium
npx playwright test --headed
npx playwright test --reporter=line
```
